Crackdown (Xbox 360) - PC port, version @VERSION@
==================================================

This is an unofficial recompiled port. It does NOT include the game. You need
your own copy of Crackdown for Xbox 360 (disc image or extracted files).

First start
-----------
1. Run crackdown.exe. The launcher opens.
2. On the Play page choose "Install from disc image..." and pick your disc
   image (.iso), or "Install from folder..." for the extracted disc files. The
   files are checked and copied to the "game" folder next to crackdown.exe.
3. Press Play.

Hold Shift while starting to open the launcher again. The launcher saves your
display, graphics and gameplay choices. A window size or monitor change
restarts the game once so the new window is used.

Where your data lives
---------------------
  game\        installed game files
  user_data\   saves, profile, cache and settings.toml
  logs\        log files

Everything is kept next to crackdown.exe. If that folder is read-only, the
program uses a per-user folder and says so in the launcher. Delete
user_data\settings.toml to reset your settings; a damaged settings file is
set aside as settings.toml.invalid and replaced automatically.

Keys
----
  F11    toggle fullscreen / windowed
  F2     show or hide the frame counter
  F7     achievements
  F10    cheats menu (settings are on the launcher's Cheats page)

Keyboard and mouse can be enabled on the launcher's Controls page, which also
lists the keys and sets the mouse sensitivity. Xbox controllers keep working.

Needs
-----
Windows 10 or 11 (64-bit), a CPU with FMA3 (Intel Haswell, AMD Piledriver or
newer), a GPU with Direct3D 12 support and the Microsoft Visual C++ 2015-2022
Redistributable (x64). On laptops with two GPUs the
high-performance one is preferred.

Known issue
-----------
Background music may occasionally stop during gameplay while sound effects and
voices continue.
