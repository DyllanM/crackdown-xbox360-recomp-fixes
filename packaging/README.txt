Crackdown (Xbox 360) - PC port, version @VERSION@
==================================================

This is an unofficial recompiled port. It does NOT include the game. You need
your own copy of Crackdown for Xbox 360 (disc image or extracted files).

First start
-----------
1. Run crackdown.exe. The launcher opens.
2. Choose "Install game files" and pick your disc image (.iso) or the folder
   with the extracted game. The files are checked and copied to the "game"
   folder next to crackdown.exe.
3. Press Play.

Hold Shift while starting to open the launcher again. The launcher saves your
display, graphics and audio choices. A window size or monitor change restarts
the game once so the new window is used.

Where your data lives
---------------------
  game\        installed game files
  user_data\   saves, profile, cache and settings.toml
  logs\        log files

Everything is kept next to crackdown.exe. If that folder is read-only, the
program uses a per-user folder and says so in the launcher. Delete
user_data\settings.toml to reset your settings; a damaged settings file is
set aside as settings.toml.invalid and replaced automatically.

Keys
----
  F11    toggle fullscreen / windowed

Needs
-----
Windows 10 or 11 (64-bit) and a GPU with Direct3D 12 support.
On laptops with two GPUs the high-performance one is preferred.
